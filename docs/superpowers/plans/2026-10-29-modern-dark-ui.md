# Modern Dark UI Implementation Plan

**Goal:** 全画面を暗色の Apple 風 UI に刷新し、余白と単純な区切りで情報を整理する。

**Architecture:** 既存の TypeScript / DOM 実装を維持する。共通 CSS を基礎・テスト画面と、管理・DB・履歴・レスポンシブの2ファイルに整理し、デスクトップログ画面にも同じ視覚方針を適用する。

**Tech Stack:** Node.js 24 / pnpm 11 / TypeScript / CSS / Electron / Python Playwright（画面検証）。

**Authorization:** ユーザーは暗色基調を選択し、「細部は任せて実装まで進める」と指定済み。デザイン選択の追加確認は不要。

## Design

- 背景 `#17181b`、サイド領域 `#1c1d21`、浮いた面 `#25272c`、文字 `#f1f2f4`、補助文字 `#a3a7b1`、操作色 `#9ac0ff`。
- システムのサンセリフを使用。本文14px、見出しは20〜30px、ID・ログだけ等幅。外部フォントは取得しない。
- 上部にアプリ名と主要4画面のナビゲーション、左に現在の画面の一覧、右に内容。重複ナビゲーションを整理する。
- テスト画面はチャット・右側ログ／ユーザー・下部ケース一覧を維持。狭い画面でも独立したスクロール領域を保つ。
- 管理画面はカード群を廃止し、見出し・リスト・フォームを余白と水平線で整理する。
- DBは読みやすい表、履歴は時間順のリスト、ログは検索・絞り込みができる平坦な画面にする。
- 過剰な角丸・枠・影・装飾番号・英大文字ラベル・キャッチコピーを除く。コントロールは下線または控えめな塗りで識別する。
- 操作直後のフィードバックと短い色／不透明度変化を使用し、モーション軽減を尊重する。

## Global Constraints

- 既存の機能、DOM IDと要素型、セッション・CSRF・管理権限境界を保持する。
- 本番 Discord 通信、外部公開、テレメトリ、新規ランタイム依存を追加しない。
- 作業中の既存変更を基点とする。現在の feature ブランチで編集し、開始時の差分と対象ファイルを `/tmp/discord-mock-redesign/before` に保存する。
- 新規JS関連ソース・テストはTypeScriptのみ。デザイン変更に実装の写しとなるテストは追加しない。
