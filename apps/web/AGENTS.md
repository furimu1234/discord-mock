# Web 開発ルール

ルートの `AGENTS.md` と本書を併せて守る。

- `apps/web` はブラウザのテスト画面と管理画面を担当する。Mock の真の状態は `apps/server` が管理する。
- ログイン中のダミーユーザーと管理者権限を混同しない。
- DM や権限判定をブラウザだけで実装しない。必ず Mock サーバー側でも検証する。
- VC の音声は参加中のユーザーにのみ提供し、退出・切替時には停止させる。
- ブラウザに本番 Discord のトークンや実ユーザー認証情報を保持しない。
- 現状の HTML は UI 構成確認用であり、Discord 互換機能が実装済みだと表示しない。
- 関連変更では `pnpm --filter @discord-mock/web test` を実行する。
